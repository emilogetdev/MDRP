# MD RP Website

Die MD-RP-Website liegt direkt im Hauptordner des Repositorys.

## Dateien
- `index.html` — Startseite
- `impressum.html` — Impressum-Hinweis
- `datenschutz.html` — Datenschutzhinweise
- `style.css` — responsives Schwarz-Rot-Design
- `script.js` — mobiles Menü und Kopierfunktion
- `assets/md-rp-logo.svg` — Logo

## Server-Informationen
- Discord: https://discord.gg/g9mTwy3BN
- Server-Code: `u5dpubfy`
- Map-Überarbeitung wird im Discord angekündigt.

## GitHub Pages aktivieren
Unter **Settings → Pages → Build and deployment** die Option **Deploy from a branch** wählen, Branch `main` und Ordner `/ (root)` einstellen.
